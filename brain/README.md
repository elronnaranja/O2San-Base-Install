# The brain

This folder is the office's memory. The Chief of Staff (and any agent added later) reads it before working and writes back after. Chats are forgotten; files here are not.

| Where | What |
|---|---|
| `about-me.md` | Who the office works for. Filled in by `/setup`. |
| `RULES.md` | What the office may and may not do. Default safety rules plus your own. |
| `state/INDEX.md` | One line per project and per agent. Start here. |
| `state/<topic>.md` | One short page per project: status, decided, open, next step. Copy `state/_template.md`. |
| `state/agent-<name>.md` | Same, for each agent. |
| `lessons/<name>.md` | Corrections saved with `/teach`. They win over the agent's habits. |
| `inbox/` | Drop zone. Put notes, files or ideas here; the Chief sorts them. |

## How it stays useful
- One page per thing, kept short. Update it, don't pile on.
- Dates as YYYY-MM-DD. When the user decides something, write their words and the date.
- Nothing is deleted. Old material moves to `inbox/archive/`.
- No passwords, keys or tokens anywhere in here.
- Works as a plain folder, or open it in Obsidian if you like linked notes (`[[page-name]]`).
